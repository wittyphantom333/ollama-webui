The name is the repository, with the quantization as a tag — not the .gguf filename:

hf.co/Orenguteng/Llama-3-8B-Lexi-Uncensored-GGUF:Q4_K_M

Omit the tag to get the repo's default quantization (Q4_K_M when present). A full filename also works as a tag. Hugging Face replies “Invalid username or password” for private, gated and misspelled repositories alike, so a 401 usually means the repo id is wrong — this page checks the Hub before starting a download and tells you which it is.
